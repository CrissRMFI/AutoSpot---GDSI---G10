# US 21C: Visualización de catálogo

**Sprint:** 3
**Actor:** Conductor
**Prioridad:** Alta

## Descripción
**Como** conductor,
**quiero** tener un catálogo de automóviles y estaciones a mi disposición,
**para** poder ver la oferta total de autos de la plataforma.

## Criterios de Aceptación

### CA 1
**Dado que** el usuario se registró satisfactoriamente,
**cuando** quiera ver el catálogo,
**entonces** el sistema debe mostrarme automáticamente la oferta completa de vehículos.

### CA 2
**Dado que** un propietario habilitó un auto para alquiler,
**cuando** el conductor actualice el catálogo,
**entonces** el sistema debe mostrar el nuevo vehículo disponible.

### CA 3
**Dado que** un propietario deshabilitó un auto que estaba en alquiler,
**cuando** el conductor actualice el catálogo,
**entonces** el sistema debe ocultar ese vehículo del catálogo.
