# US 3R: Abrir documentación

**Sprint:** 3
**Actor:** Recepcionista
**Prioridad:** Alta

## Descripción
**Como** recepcionista,
**quiero** abrir los detalles de la solicitud de los usuarios,
**para** revisar los documentos.

## Criterios de Aceptación

### CA 1
**Dado que** un usuario envió una solicitud de validación para revisión de documentos,
**entonces** quiero poder entrar a sus detalles y visualizarlos correctamente.

### CA 2
**Dado que** un usuario malicioso envió una solicitud vacía para revisión de documentos,
**entonces** quiero que el sistema no la incluya.
